TIME TRAVEL --> at(offset), at(timestamp), before(statement => statement_id)
-----------     ------------------------------------------------------------

In this we can go back to the time where u have deleted the data and we can view that data, if u want to restore the deleted data either u have to go with insert into command or create table as command.

example;

insert into employee
select * from 
employee before(statement => 'statement_id')


create table <table_name> as 
select * 
from employee
before(statement => 'statement_id')

        id int,
        name varchar
);

insert into raw_tbl values

(2, 'ravi');

select * from raw_tbl;

delete from raw_tbl where id = 2;

select * from raw_tbl at(offset => -60*7);

FINAL UNDESTANDING ABOUT TIME TRAVEL, FAIL SAFE & CLONING;
-----------------------------------------------------------

AT(OFFSET => SECONDS) --> VIEW OLD DATA AT EXACT SECONDS BACK
AT(TIMESTAMP => TIMESTAMP) --> VIEW DATA AT EXACT TIMESTAMP
BEFORE(STATEMENT => STATEMANT_ID) --> VIEW DATA BEFORE THAT STATEMENT_ID HAS EXECUTED
UNDROP --> RECOVER DELETED OBJECTS LIKE TABLES, SCHEMAS & DATABASES
CLONE --> CPOING DATA
INSERT + TIME TAVEL --> RECOVER DELETED DATA
